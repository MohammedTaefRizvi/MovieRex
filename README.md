# MovieRex
🎬 MovieRex – Personalized Movie Recommendation System <br>
MovieRex is a content-based movie recommender system that suggests films based on user preferences by analyzing movie features such as genre, keywords, and overview. It uses cosine similarity to measure the closeness between movies and recommend titles similar to what users already like. <br>
The system is built with Python and deployed using Streamlit, offering a clean, interactive frontend for users to explore recommendations with ease. Ideal for movie lovers who want smart, tailored suggestions! <br>
Dataset --> https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata
